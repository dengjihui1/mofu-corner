绒角 MofuCorner 0.6.1
给桌面一角，添一点毛茸茸。

要求：Node.js 22.12+（含 npm）、Windows / macOS 图形桌面、WebGL2。
下载 Node：https://nodejs.org/

在包含 setup.mjs 的目录打开终端，运行：node setup.mjs
首次会自动准备依赖和 Electron，然后打开小窝；后续保留已保存设置。
Windows 也可双击 Start-MofuCorner.cmd。
Mac 可运行 bash Start-MofuCorner.command。
旧 Start-PaperPal 入口仍兼容。

托盘 / 菜单栏：打开设置、桌面陪伴、窗口外侧陪伴、退出。
小窝可选择十二生肖和经典小獭；设置昵称、55%–130% 身量和三种性格。
在“照顾它”配置好后点“保存并收起”。默认身量 60%。

重新打开设置：node setup.mjs --configure
Lark 标识启动：node setup.mjs --brand lark
只准备环境：node setup.mjs --no-start
修复依赖：node setup.mjs --repair
浏览器预览：npm run preview
本机检查：npm run doctor

默认无需账号或企业审批，不读取聊天、不接收真实消息、不修改飞书状态。
窗口跟随只读进程与窗口位置；客户端不在前台、最小化或外侧放不下时隐藏。
Mac 真实客户端跟随仍为试用。可从托盘切回桌面陪伴。
浏览器预览不具备原生桌面能力，设置与桌面版分别保存。

本地设置：.local/。更新时保留此目录，不跨系统复制 node_modules。
卸载：从托盘退出后，备份所需配置，再删除项目目录。
完整图文说明：https://github.com/dengjihui1/mofu-corner
