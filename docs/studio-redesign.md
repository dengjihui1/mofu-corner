# 绒角 · 生活方式视觉迭代

2026-10-31。用户明确认为旧版过于儿童化，要求更高级、年轻。因此重新选择视觉方向，不继承上一轮奶油粉色大圆角系统。

## 设计依据

- taste-skill Editorial greeting，seed 1417817864。workspace/home/builder/inbox，明亮主题。
- 原则：毛绒伙伴有亲和力，房间与操作界面体现年轻人的生活方式。
- 产品自身元素：十二生肖固定账号身份、真实毛绒原画、三类可穿饰品、37件收藏品、四个房间搭配、自由摆放坐标、真实绒绒豆余额、好友邀请、双方同意的关系、聊天和桌面同步。
- 主问题：我的伙伴住在这套空间里是什么样？主视觉由可编辑的真实房间回答。注册与聊天沿用同一视觉系统。
- 视觉特征：雾灰绿底、深墨文字、白色单层面板；家具使用亚麻、木面、陶器和克制的莓果色，毛绒角色不重新生成。
- 布局：1100px内容，12 × 77px + 11 × 16px；主房间9列、选择3列，平板8/4，手机纵排。
- 字体：Instrument Sans 400/500/600，自托管来自Google Fonts的字体与OFL许可证；中文用系统PingFang SC / Microsoft YaHei UI，不依赖境外字体服务。
- 无新权限、假社交人数或修改价格。已有账号、饰品与房间数据继续使用。

## 变化范围

房间道具SVG、材质、四个搭配，展厅、登录、聊天、衣橱、商店、编辑器和照片边框。保留原画、动作、定位、商品ID、所有权、余额和好友接口。

## 检查

- 实际 CUA 浏览器检查 1280px 桌面、768px 平板、390px 手机，四套房间及登录页面；场景比例统一为 1.6，避免窄屏上家具拉伸。首轮发现侧栏偏高，缩小缩略图和行内留白后复查。
- 逐张目视登录、聊天、手机衣橱截图。手机衣橱使用单层滚动，试戴与购买区域保持可见。
- 主项目 74 项单元测试通过，113 个 JavaScript 文件语法检查通过；云端 API / 经济与构建检查通过。
- 房间编辑 25 项、邀请与社交 27 项、小屋 UI 12 项回归通过；照片导出为 1512×1064，宠物位置与实际房间一致。
- 真实 Electron / preload / 云端网页联调通过：外部换装约 5004ms 同步，摘除、断网、切换账号、会话撤销正常。本次本机环境为 Windows，不声称完成 Mac 实机验收。
- 37 个目录 ID、价格、位置和其他业务字段与上一版本一致，仅修改名称和颜色；默认房间与奖励规则保持一致。

字体来源为 Google Fonts 官方 Instrument Sans（400 / 500 / 600），自托管 TTF 共约 146KB；许可证随资源提交，网页不请求外部字体服务。
